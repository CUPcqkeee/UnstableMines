# ⛏️ UnstableMines

## ✨ Возможности

- **Риск обрушения растёт** при добыче каменных пород в подземных тоннелях и после взрывов поблизости.
- **Сначала предупреждение, потом обрушение.** Частицы трещин, звуковой сигнал и уведомления в action bar дают время среагировать.
- **Обрушение возвращает выкопанную породу** на прежние места или сбрасывает её на игрока — в зависимости от выбранного режима. Если выкопанной породы недостаточно, могут осыпаться блоки потолка.
- **Деревянные опоры снижают риск** и помогают сохранить проход; уведомление об укреплении также появляется в action bar.
- **Риск постепенно убывает**, если шахту не тревожить.
- Русский и английский языки, настраиваемое имя плагина в сообщениях.

## 📥 Установка

1. Скачай готовый JAR из раздела **Releases** или собери его самостоятельно.
2. Помести `UnstableMines-1.0.jar` в папку `plugins` сервера Paper.
3. Запусти сервер. Плагин создаст файлы конфигурации и переводов.
4. При необходимости измени `plugins/UnstableMines/config.yml` и выполни `/unstablemines reload`.

> Требуется сервер **Paper 1.21 или новее** и Java 21+. Для сборки требуется подключение к репозиторию Paper API.

## ⚙️ Настройка

Основные параметры находятся в `plugins/UnstableMines/config.yml`:

| Параметр | По умолчанию | Описание |
|---|---:|---|
| `language` | `ru` | Язык: `ru` или `en` |
| `plugin-name` | `Шахта: ` | Имя, подставляемое вместо `{plugin}` в сообщениях |
| `risk.mining-increase` | `8` | Прибавка риска при добыче |
| `risk.explosion-increase` | `30` | Прибавка риска после взрыва |
| `risk.warning-threshold` | `40` | Порог предупреждения |
| `risk.collapse-threshold` | `75` | Порог проверки на обрушение |
| `risk.collapse-chance` | `15` | Шанс обрушения в процентах при росте риска выше порога |
| `risk.decay-per-minute` | `2` | Снижение риска за минуту |
| `risk.support-relief` | `30` | Снижение риска от деревянной опоры |
| `risk.collapse-delay-ticks` | `60` | Задержка перед обрушением в тиках (20 тиков = 1 секунда) |
| `risk.player-notice-radius` | `24` | Радиус получения уведомлений |
| `collapse.mode` | `RESTORE_MINED_BLOCKS` | Способ обрушения |
| `collapse.maximum-mined-blocks` | `32` | Максимальное число блоков в одном обрушении |
| `collapse.maximum-tracked-blocks-per-section` | `128` | Лимит запоминаемых выкопанных блоков на участок |
| `cracks.particle` | `BLOCK` | Тип частицы для трещин |
| `cracks.material` | `STONE` | Материал осколков для частицы `BLOCK` |

### Режим обрушения

В `collapse.mode` укажи один из режимов:

- `RESTORE_MINED_BLOCKS` — вернуть часть ранее выкопанных игроком блоков на их исходные места.
- `FALL_ON_PLAYER` — сбросить выкопанные блоки сверху на последнего игрока, добывавшего блоки на участке. Если игрок недоступен или блоков нет, плагин сначала попробует вернуть блоки на места, а затем вызовет осыпание потолка.

Риск и записи о выкопанных блоках хранятся в памяти и очищаются при перезапуске сервера.

### Переводы

Сообщения находятся в `plugins/UnstableMines/messages_ru.yml` и `plugins/UnstableMines/messages_en.yml`. Измени `language` в конфигурации, чтобы выбрать язык. В тексте можно использовать `{plugin}` — он заменяется значением `plugin-name`.

## 💬 Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/unstablemines reload` | Перезагрузить конфигурацию и переводы | `unstablemines.admin` |

Право `unstablemines.admin` по умолчанию выдано операторам.

## 🛠️ Сборка из исходников

```bash
mvn clean package
```

Готовый файл появится в `target/UnstableMines-1.0.jar`.
